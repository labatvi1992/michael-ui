## Usage

```tsx
import { App } from 'michael-ui';

export default () => {
  return <App />;
};
```


## When To Use

- Provide reset styles based on `.ant-app` element.
- You could use static methods of `message/notification/Modal` from `useApp` without writing `contextHolder` manually.
