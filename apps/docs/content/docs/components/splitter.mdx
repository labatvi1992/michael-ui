## Usage

```tsx
import { Splitter } from 'michael-ui';

export default () => {
  return <Splitter />;
};
```


## When To Use

Can be used to separate areas horizontally or vertically. When you need to freely drag and adjust the size of each area. When you need to specify the maximum and minimum width and height of an area.


## API Reference

Common props ref：[Common props](/docs/react/common-props)

&gt; The Splitter component needs to calculate the panel size through its child elements, so its child elements only support `Splitter.Panel`.
