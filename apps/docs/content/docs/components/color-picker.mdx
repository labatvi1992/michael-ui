## Usage

```tsx
import { ColorPicker } from 'michael-ui';

export default () => {
  return <ColorPicker />;
};
```


## When To Use

Used when the user needs to make a customized color selection.

#### ColorType

```typescript
type ColorType =
  | string
  | Color
  | {
      color: string;
      percent: number;
    }[];
```

#### PresetColorType

```typescript
type PresetColorType = {
  label: React.ReactNode;
  defaultOpen?: boolean;
  key?: React.Key;
  colors: ColorType[];
};
```
