# Dynamic Theming

`michael-ui` comes with a powerful Design Token system and instant client-side theme switching via `ConfigProvider`.

## Theme Algorithms

Ant Design provides built-in algorithms for dark mode and compact density:

```tsx
import { ConfigProvider, theme } from 'michael-ui';

// Dark Mode
<ConfigProvider
  theme={{
    algorithm: theme.darkAlgorithm,
  }}
>
  <App />
</ConfigProvider>

// Compact Mode
<ConfigProvider
  theme={{
    algorithm: theme.compactAlgorithm,
  }}
>
  <App />
</ConfigProvider>

// Dark + Compact combined
<ConfigProvider
  theme={{
    algorithm: [theme.darkAlgorithm, theme.compactAlgorithm],
  }}
>
  <App />
</ConfigProvider>
```

## Custom Design Tokens

Easily modify brand colors, border radius, fonts, and dimensions:

```tsx
<ConfigProvider
  theme={{
    token: {
      colorPrimary: '#722ed1', // Custom purple brand color
      borderRadius: 8,         // 8px rounded corners
      fontSize: 14,
    },
  }}
>
  <App />
</ConfigProvider>
```
